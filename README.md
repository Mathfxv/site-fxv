# Site web FxV Solution

Site principal de fxvsolution.com, hébergé sur Netlify.
Chaque modification envoyée sur la branche `main` est publiée automatiquement.

- `index.html`, `remise-en-forme.html`, `athletes.html`, `coaching-en-ligne.html`, `confidentialite.html` : les pages
- `css/`, `js/`, `img/` : le style, le script du formulaire et les images
- `_redirects` : redirections des anciennes adresses Shopify vers le nouveau site et vers boutique.fxvsolution.com
- `sitemap.xml`, `robots.txt` : fichiers pour Google
